# fam-ui version 1 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `fam-ui` version 1, a plain-CSS package (tokens, materials, effects, components, three templates) with its processed textures, credits and a test suite that includes a rendered-pixel contrast audit.

**Architecture:** Five CSS layers in `css/` are concatenated by a maintainers-only script into `dist/fam-ui.css`. Both locations sit one level below the package root, so `url(../assets/...)` resolves from either. Every rule is ported from the approved prototype and checked against it or against the spec's numbers by Playwright tests running in the installed Google Chrome.

**Tech stack:** CSS, Node 26 (`node:test`, `playwright-core` driving installed Chrome, `pngjs`), Python 3 with Pillow and ImageMagick for texture and contrast tooling (maintainers only).

**Spec:** `docs/superpowers/specs/2026-10-22-fam-ui-design.md`. **Prototype (the oracle for the look):** `docs/superpowers/reference/demo-reference.html`, cited below as `ref:LINE-LINE`. Its assets are in `docs/superpowers/reference/demo-assets/`.

## Global constraints

- Plain CSS. No required build step and no required JavaScript for consumers. Bundle, texture and audit tooling is for maintainers only.
- Class prefix `fam-`, custom property prefix `--fam-`, package name `fam-ui`. Tokens live on `:root`. The optional `.fam` wrapper only sets typography. Every component sets its own `box-sizing: border-box`.
- Glass: the filter layer gets a real `border-radius`. Never round a `backdrop-filter` with `clip-path` or `overflow: hidden`. Lens `blur(14px) saturate(125%) brightness(110%)` over a 42% black shade, glow `blur(25px) saturate(190%) brightness(135%)`, `--fam-glow-depth: 18px`, bleed `2rem`. Refraction is `url(#fam-refract) blur(1px) saturate(110%) brightness(105%)`, Chromium only, with a clear-pane fallback.
- Blue family `#406eda` to `#2f5fc8`, white text on it at 4.9:1 or better. Navigation never uses blue.
- WCAG AA measured on rendered pixels at the worst pixel: normal text 4.5:1, large text (24px, or 18.66px bold) 3:1, icons 3:1. Zero failures in the audit; never loosen the threshold to pass.
- Each shipped tile is roughly 150 KB or less. A default example page loads 1.5 MB or less.
- Shipped assets derive only from the owner's `textures/` photos. Reference screenshots (`references/`) are never shipped. No rubber style. No "Tasks" template in version 1.
- CSS comments only for WHY. Prose in README and CREDITS uses sentence-case headers and no em dashes (use a spaced hyphen).
- Commits are imperative, one per task, with the trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- The collector skips text inside `<header>`, `[aria-hidden="true"]` and `svg`. Never put real template text inside `<header>`.

## Review focus

The spec is silent on these; each has a test in the named task.

1. Keyboard focus: every interactive control shows a visible focus indicator (Task 5).
2. `prefers-reduced-motion: reduce` stops the candy cane animation (Task 5).
3. Long text (a 200 character nav item, list row title or glass input value) stays inside its container (Task 5).
4. A 375px wide phone viewport: no horizontal page scroll on any template (Task 7).
5. The package consumed from another directory, where a page and the stylesheet are in different folders: textures still load (Task 9).
