Glass: frosted vs. refracting

Each strip is leather, metal spiral, a bright rainbow with colored dots, and wood. Each lens sits on a seam so it picks up two materials at once. The top row is the frosted recipe from ~/shiny. The bottom row is clear glass with edge refraction from an SVG displacement filter.

Frosted (~/shiny recipe)
Refracting (SVG filter)

The refraction row relies on SVG filters inside backdrop-filter, which Chromium supports. Other browsers would show a clear pane without the bending.
