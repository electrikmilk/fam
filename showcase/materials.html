Materials

One class for every texture

Each material is a single class on any box. Felt takes a tint, cardstock takes a tint, and gloss, rounding and shadows are classes too. Below the textures are the navigation bars, photo frames and engraved text made from them, then scenes that pair materials, each with its markup and a button that copies it.
