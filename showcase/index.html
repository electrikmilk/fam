Fam

Familiar materials for the web

Familiar on purpose

Skeuomorphism exists to make an interface feel familiar. A recessed field invites typing, a raised button invites a press and a switch looks like a switch. Fam builds those cues from photographs of real materials.

Real photographs

Every texture is processed from an Unsplash photograph, made seamless and credited. The grain is real, not a gradient imitation of it.

12 KB smallest tile

Light on the wire

Each material is a tile between 12 KB and 85 KB. The notes example loads 250 KB of images and 92 KB of CSS (20.7 KB gzipped), with no JavaScript.

Responsive by tiling

A tile repeats at its natural size and is never stretched, so any box in any shape gets the material. There are no images per breakpoint, and a phone loads the same files as a desktop.

AA WCAG contrast

Built to ship

Contrast is measured on the rendered pixels against WCAG AA. Every control has a keyboard focus ring, and forced colors, disabled states and missing backdrop blur are handled. It is one stylesheet with fam- classes.

Use all of it, or just a little

Fam is a full UI framework when you want one, and a layer of texture when you do not. The materials are plain classes, so they sit under a minimalist, flat UI as easily as under Fam's own controls.

Play Stop

As a UI framework

Use the buttons, switches, tabs, fields, lists, navigation and glass. Every control is built from the materials and works with the keyboard, so a whole interface can be Fam.

Flat card Continue

As texture for a flat UI

Keep your own minimalist components and put a material behind them, such as cork, wood, felt or leather. You add one class, and only the tile you use is downloaded.

HTML
<div class="fam-cork" style="padding: 32px">
  <!-- your own flat components -->
  <div class="card">...</div>
</div>
